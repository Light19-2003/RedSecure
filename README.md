# RedSecure — IT Solutions

A premium, responsive redesign of the RedSecure company website built with
Next.js App Router, React, and Tailwind CSS for deployment to Vercel.

The implementation preserves the original services, products, company copy,
contact details, map, forms, social links, and legacy `.html` routes.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
npm test
npm run lint
```

## Deploy to Vercel

Import this repository in Vercel. Vercel will detect Next.js automatically and
use the standard `npm run build` command with `.next` as the build output.
